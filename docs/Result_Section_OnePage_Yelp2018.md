# 4.X 实验结果与讨论（Yelp2018，一页终稿）

## 4.X.1 实验设置
为验证所提层聚合改动的有效性，本文在 Yelp2018 数据集上对两种 LightGCN 聚合策略进行对比：原始均值聚合（mean）与可学习加权聚合（learnable，采用最佳调参配置）。
比较采用配对设计：随机种子固定为 2020、2021、2022；模型均为 3 层、64 维，基于 300 epoch checkpoint 评估；Top-K 指标为 Precision、Recall、NDCG（K=10/20/50）。

## 4.X.2 Top-K 主结果
3-seed 平均结果显示，mean 在所有 K 与全部指标上均优于 learnable，且逐 seed 的差值方向一致（mean - learnable 始终为正）。代表性结果如下：

- Precision@10/20/50：
  - mean: 0.032204 / 0.027677 / 0.021751
  - learnable: 0.024805 / 0.021793 / 0.017707
  - 差值: +0.007399 / +0.005884 / +0.004044
- Recall@10/20/50：
  - mean: 0.036223 / 0.061774 / 0.119547
  - learnable: 0.027688 / 0.048261 / 0.096989
  - 差值: +0.008535 / +0.013513 / +0.022558
- NDCG@10/20/50：
  - mean: 0.041279 / 0.050629 / 0.072150
  - learnable: 0.031276 / 0.038938 / 0.057071
  - 差值: +0.010003 / +0.011691 / +0.015079

该结果说明：本文引入的可学习层加权在当前任务设定下未带来性能增益，原始均值聚合反而更稳健。

## 4.X.3 收敛趋势与效率量化
基于 TensorBoard 事件文件绘制的收敛曲线（Recall@20、NDCG@20）表明，mean 在训练过程中整体轨迹持续高于 learnable-best。末端观测点上，mean 的 Recall@20 为 0.061778、NDCG@20 为 0.050662；learnable-best 分别为 0.047173 与 0.038075。该现象与 Top-K 表格结论一致，说明差异并非只体现在最终单点，而是贯穿收敛过程。

进一步地，本文将收敛曲线量化为“阈值达成步数 + 归一化 AUC”两类指标（阈值定义为 mean 最终值的 95%）：

- Recall@20（阈值 0.058689）：
  - mean：130.0±0.0 step 达标，Norm-AUC = 0.056076±0.000064
  - learnable-best：未达到阈值，Norm-AUC = 0.042987±0.000381
- NDCG@20（阈值 0.048129）：
  - mean：143.3±4.7 step 达标，Norm-AUC = 0.045535±0.000071
  - learnable-best：未达到阈值，Norm-AUC = 0.034823±0.000359

因此，从“达标速度”和“全过程积分表现”两方面，mean 均明显优于 learnable-best。

## 4.X.4 统计显著性补充
在原始 mean vs learnable-best 统计基础上，本文进一步加入 L2 变体（layer_w_l2=1e-3）的配对统计升级，形成“mean / learnable-best / learnable+L2”三方对照。核心结果如下：

- K=20 下，mean - L2 的配对均值差：
  - Precision@20: 0.005971，95% CI [0.005744, 0.006151]，p=0.25
  - Recall@20: 0.013832，95% CI [0.013063, 0.014425]，p=0.25
  - NDCG@20: 0.011880，95% CI [0.011544, 0.012080]，p=0.25
- K=20 下，L2 - learnable-best 的配对差：
  - Precision@20: -0.000086，95% CI [-0.000467, 0.000546]，p=1.00
  - Recall@20: -0.000318，95% CI [-0.001271, 0.001390]，p=1.00
  - NDCG@20: -0.000189，95% CI [-0.000904, 0.001238]，p=1.00
- 相对 mean 的差距变化（K=20）：
  - Precision: -1.47%
  - Recall: -2.36%
  - NDCG: -1.62%

上述结果表明：L2 变体在当前设置下未带来可验证提升，且相对 mean 的差距轻微扩大。由于样本量仅 3，p 值应视为保守证据；但方向结论稳定，即 mean 仍是最优聚合策略。

## 4.X.5 小结
综合 Top-K、收敛曲线、收敛效率量化与统计升级四类证据，在 Yelp2018 上，mean 聚合相较 learnable-best 与 learnable+L2 均表现更优且更稳定。该结果对本文同样具有研究价值：它表明在当前数据规模与训练范式下，增加层权重自由度及轻量 L2 正则并未转化为更优泛化，反而可能引入额外优化复杂度。
